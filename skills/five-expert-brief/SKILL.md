# 调研简报（Research Brief）

`five-expert-panel` 技能组的第三棒。前两棒分别把东西**摆全**（五视角）和**磨出结论**（矛盾图），这一棒只做一件事：把它压成一份能被真用上的东西。

判据很简单——**简报的读者能不能在读完的下一分钟做出一个不同的决定**。做不到，就是写作失败，不是主题不行。

## When to Use（何时用）

- 五视角和矛盾图都跑完了，需要给老板/客户/自己一份结论
- 用户说“总结一下”“给我一份简报”“我该做什么”“还有什么是我们没问的”
- 要把调研变成文章大纲或投资/项目决策依据

不适用：还没跑前两步（先去跑，简报不能凭空造）；或者用户只要一段聊天回复。

## 输入契约

理想输入：五视角输出 + 矛盾图（含证据强度排序、keystone question、共识与沉默）。

如果只有五视角、没有矛盾图：先内联做一遍精简版矛盾图（拆伪冲突 → 证据排序 → 挑 keystone），不要跳过证据排序直接写发现——**没有可靠度排序的“五条发现”只是五条并列的想法**。

## 五块产出

### 1. 60 秒总结（一段话）

写一段话，给只有 60 秒、且不打算追问的人。

**硬指标**：中文 200–260 字（对应口播 60 秒），一段，无标题、无小标题、无列表。

必须含四样，一样不能少：
- **结论**：到底怎么回事，一句说完
- **量级**：最大的那个数字或尺度（没有数字就用可感知的对比）
- **最大的不确定**：你在哪儿可能错，错得有多疼
- **方向**：接下来该往哪边用力

**禁止**：
- 标题党语气（“颠覆”“彻底改变”“所有人都该知道”）
- 开头用“随着……的发展”“近年来，随着……”
- “具有重要意义”“前景广阔”“值得关注”这类零信息量句
- 为了显得客观而两头下注（“既有机遇也有挑战”）

**检验方法**：把这段话给一个不了解背景的人读一遍，问他“所以你建议我干什么？”他能答出来，就合格。

### 2. 五个关键发现，按可靠度排序

注意：**排序依据是“我有多确信”，不是“有多重要”**。这是这份简报最容易错的地方——多数人把五个发现按劲爆程度排，CEO 读完把最劲爆的那个当成最确定的，然后做错决定。

每条发现给四个字段：

| 字段 | 要求 |
|---|---|
| 发现 | 一句可证伪的陈述句，不是话题名 |
| 可靠性 | 高 / 中 / 低，并给依据（证据层级、独立印证数、是否被打过） |
| 支持方 | 哪几个视角背书（写视角名） |
| 反对方 | 哪几个视角反对，反对的理由是什么 |

**可靠性分级标准**（沿用矛盾图的五维，压缩成三档）：
- **高**：至少两个不同方法论/不同利益方的视角独立支持，且证据可核查、未被同行击倒
- **中**：只有一方硬支持，其他方沉默；或证据层级高但只有单一来源
- **低**：主要靠单人经验、历史类比、或利益相关方的数据支撑

**强制要求**：五条里至少要有一条是“高可靠性但平淡”的。如果五条全是惊人结论，说明你在挑爽的写，不是在排序。

### 3. 隐藏关联（本技能的核心产出）

五个视角各自单独看都看不见、**叠加到三个以上才浮现**的那层东西。这是整套方法真正的溢价所在。

**判据（三条同时满足）**：
1. 只用任意单个视角推不出来
2. 只用两个视角也推不出来（只能推出普通联系，不是隐藏关联）
3. 说出来之后，回头能让至少三个视角的处境同时变得可理解

不满足第 2 条就降级成“联系”，不要冒充隐藏关联。

**常见的三种真关联结构**：

| 结构 | 长相 | 例子 |
|---|---|---|
| 机制镜像 | A 看到的果，恰好是 B 所在激励结构的因 | 学者测出的效应量小 ↔ 供应商的推广激励要求“无条件适用” → 效应量小不是方法无效，是规模化时边界条件被剥掉了 |
| 时间错配 | 一方看长期、一方看短期，两边都对，但中间存在必爆的缺口 | 实践者的现金流压力周期 ↔ 学者的十年趋势 → 趋势正确但没人能活到那天 |
| 见证偏差 | 一方的数据样本，另一方的沉默恰好解释了为什么 | 实践者只见到活下来的项目 ↔ 经济学家只统计成功案例的收入 → 失败者系统性消失 |

**必须标注强度**：机制已解释 / 机制成立但未验证 / 纯推测。不许把第三种写成第一种。

### 4. 一条行动建议（绑定用户角色）

“一条”，不是五条。给五条等于没给。

必须绑到**具体角色**上——同一个调研，投资人、工程师、内容作者、部门负责人该做的事完全不同，不写角色就是写给所有人，等于写给没人。

四个字段：
- **我现在的默认做法**：如果不看这份简报，我会怎么做（先把惯性说出来）
- **该改成什么**：具体到这周/这个季度能动手的动作，不是“加强关注”“持续跟踪”这种伪行动
- **为什么现在**：时间窗口在哪，为什么不是下季度再说
- **止损信号**：什么现象出现，就说明这个判断错了，立即回撤

**允许的答案包括“不做”**：如果调研结论是“这块没油水”，那么“停止投入”就是最具体的行动。不要为了凑一个正面动作而无中生有。

**禁止的伪行动**：“保持关注”“建立认知”“加强沟通”“持续观察”。这些不是行动，是拖延的礼貌说法。

### 5. 一个前沿问题

与矛盾图里的 Keystone Question **不是同一类东西**，不要混：

| | Keystone Question | 前沿问题 |
|---|---|---|
| 面向 | 向内，消解已有分歧 | 向外，更换坐标系 |
| 答完之后 | 现有冲突重新排列 | 我们对主题的**理解框架**变了 |
| 检验 | 能让至少两对冲突重排 | 能让“现在这个问题本身”变得不重要或换一种问法 |

**判据**：如果这个问题的答案是 A，整个领域的讨论会往另一个方向走；如果是 B，则维持现状。两边都有意义，才叫前沿问题。

**必须附三样**：
- 为什么现在答不了（数据/方法/伦理/现象太新）
- 什么条件下能答（技术突破、数据积累、某个自然实验）
- 如果答案是 X，我们现在的哪个结论会被推翻

找不到就写“当前没有能换框架的问题，领域处于常规推进期”——这也是有价值的判断，比硬凑一个像论文选题的问句诚实。

## 输出模板

```markdown
# <主题>：调研简报

> 面向：<角色>　｜　日期：<日期>　｜　置信度：<整体高/中/低>

## 60 秒
<200–260 字一段话：结论、量级、最大不确定、方向>

## 五个发现（按确信度降序）

### 1. <陈述句>
- 可靠性：高　| 支持：学者、经济学家　| 反对：实践者（理由：……）
- 依据：……

（2–5，格式同上）

## 隐藏关联
> <一句话把关联说出来>

- 参与视角：A + B + C
- 机制：……
- 强度：机制已解释 / 未验证 / 推测
- 为什么单看任何一个视角都看不见：……

## 行动建议
- 我的默认做法：……
- 改成：……
- 为什么现在：……
- 止损信号：……

## 前沿问题
> <一句问句>

- 为什么现在答不了：……
- 什么条件下能答：……
- 若答案为 X，会被推翻的结论：……
```

## 质量红线

- **60 秒里不许出现形容词堆砌**。每一句都要能回答“所以呢”。
- **发现是按确信度排的，不是按劲爆程度排的**。排序错了，整份简报就是在误导决策。
- **不许把“联系”包装成“隐藏关联”**。两个视角就能推出来的东西，老实写成“联系”。
- **行动建议只能一条**。给多条等于把决策退回给读者。
- **不许写给“所有人”的建议**。不绑角色就没有执行力。
- **前沿问题不许与 Keystone 重复**。如果两个问句实质上一样，说明你还没想清楚框架层的问题。
- **数字不核不发**。未核实的量级要么去查，要么明写“待核”，不许用看起来专业的约数蒙混。

## 与其他技能的分工

- 上游：`five-expert-panel`（五视角）→ `five-expert-conflict-map`（冲突、证据排序、keystone）
- 本技能：一份可直接用的简报
- 必走：`five-expert-peer-review`（发布或据此行动之前先做对抗性评审。不评审就发，等于拿没测过的代码上线）
- 下游：`five-expert-curator`（把结论落成一周能执行的学习路径）、写作类技能（简报的 60 秒段常常就是文章开头，隐藏关联常常是文章立意）
