# 同行评审（Adversarial Peer Review）

`five-expert-panel` 技能组的第四棒，也是唯一一棒**反向**的：前三棒建东西，这一棒拆东西。

简报写完的那一刻是最危险的时刻——它读起来很顺，因为你刚刚把它造得很顺。流畅感会被误认为可靠度。这一棒的任务是把自己写的简报当成别人的稿子，假定它有病，找到病。

## When to Use（何时用）

- `five-expert-brief` 已产出，发布/上交/据此行动之前
- 用户说“评审一下”“打个分”“还有哪里不牢”“会不会被专家笑”
- 要把简报当文章发表、当决策依据、当对外材料

不适用：还没有简报（先去跑前三步）；或者用户只是想找个理由确认自己写得很好——那种情况下这个技能会让他不舒服，那正是它的作用。

## 评审立场（先确立，否则会走过场）

评审者必须假设：**这份简报是别人写的，且很可能有错**。心里默念一句：“如果我能找到一条能推翻它的证据，我就会推翻它。”找不到再承认它结实。

禁止的评审句式：“整体很好”“建议补充一些数据”“可以再深入一些”“结构清晰”。这些是客套，不是评审。

## 五块产出

### 1. 五个发现逐个打分（1–10）

裸分数没有意义，必须有锚。用下面这张尺子，每条分数必须落在具体档位并说明**扣分扣在哪一维**：

| 分档 | 含义 | 典型证据形态 |
|---|---|---|
| 9–10 | 多源、不同方法论独立印证，可核查，已被攻击而未倒 | 元分析 + 独立复现 + 反向利益方也承认 |
| 7–8 | 硬证据但单一来源，或两方印证但未被打过 | 高质量单研究、可核查的一手数据 |
| 5–6 | 方向可能对，但证据形式弱 | 轶事集合、历史类比、利益方自报数据、机制推断 |
| 3–4 | 只有主张，没有可核查证据 | 专家意见、共识直觉、“行业都这么说” |
| 1–2 | 已有反证未被处理，或现象本身无法支撑该结论 | 被推翻的研究、反向数据已存在 |

每条必须给四行：
- **分数 + 落在哪一档的理由**
- **扣分点**：可核查性 / 层级 / 效应量 / 独立性 / 反证存活，哪几项扣了
- **升 2 分需要什么**：具体哪一种证据能让它上一个台阶
- **降 2 分会怎样**：如果它其实是低一档，简报里哪句话必须删

**防评分通胀**（硬规则）：五条分数必须至少跳开三个不同整数档。如果五条全在 7 分以上，评审本身不合格，重做——那不是严格，那是奉承。同理，如果五条全在 5 分以下，你写的不是评审，是自我攻击表演，也要重做。

### 2. 最没把握的那一条

选中的标准不是“最不重要”，而是 **`错得起的程度 × 错的可能性` 最大的那一条**——也就是“一旦它倒了，整份简报的结论跟着倒”的那一条。

按这两条分别打分：
- **影响半径**：它错了，简报里还有几句话跟着站不住？
- **倒下的概率**：现有反证、样本问题、利益相关性、被撤回风险

两样都高的才入选。影响力大但基本不可能错的，不选。

然后必须给出**验证方案**，四要素：
1. 需要什么具体信息（不是“更多数据”，是“哪一年的什么口径的什么数据，谁手里有”）
2. 怎么拿（公开数据集 / 访谈 / 自然实验 / 供应商反查）
3. 成本（小时/天，是否付钱）
4. **拿不到怎么办**：改写成条件结论（“在 X 成立时……”）、降级为待核项、还是换一条不依赖它的发现顶上。

这一块是整个评审里最实用的一部分：它告诉你该去哪里花下一个小时。

### 3. 哪个视角占比过大

先量化，再判断，不要凭感觉：

- **计数**：正文里每个视角被**正向引用**的次数（被提及不算，被否定也不算）
- **叙事线**：把五个视角名字遮住，看简报的段落顺序、因果链是按谁的框架搭的
- **行话检测**：行动建议里用的是谁的语言（“ROI”“显著性”“周期”“车间节拍”）
- **反对位置**：其他四个视角是不是只出现在“反对意见”那一行里

占比过大通常不是因为那个视角对，而是因为**转述摩擦最小**：学者有现成文献可引，经济学家有现成数字，实践者的话难引用又难验证。谁最好引用，谁就默默当了主角。

修复不是简单“给别的视角加段”，而是三选一：
- 把主导视角的**边界条件**写进结论（“仅当……时成立”）
- 把主导视角的**利益位置**写进去（它的结论对它有好处吗）
- 把被打成“反对意见”的视角**升格为并列解释**，并说明为何没采用

### 4. 第六个视角

先判定该不该加。加进来的前提是**三条全中**：
1. 它回答一个现有五个视角**结构上无法回答**的问题（不是补充细节）
2. 加了它，至少一条关键发现的分数会变
3. 它的立场不是现有某个视角的换皮

不满足第 2 条，那只是“背景补充”，不要当新视角，直接写成一句注。

常见真正能改变结论的候选（按命中率排）：

| 候选视角 | 它问的问题 | 为什么容易改变结论 |
|---|---|---|
| 维护者/运维者 | 三年后这东西谁来养、养得起吗 | 把一次性收益拉成全周期成本，常直接推翻 ROI |
| 监管者/合规 | 这套东西合法吗，谁担责 | 一纸规则可让整条路径作废 |
| 上游供应商源头 | 货源/产能/价格谁控制 | 卡脖子处常是真正的约束 |
| 受害者/非客户 | 成本转嫁给了谁 | 外部化成本一旦被定价，经济账重算 |
| 统计学家/方法论者 | 这个因果是真的吗 | 常把相关打成巧合 |
| 静默的失败者 | 死掉的那批人呢 | 幸存者偏差一补，结论强度常降一档 |

**也要允许答“不需要第六个视角”**，并说明现有五方如何已覆盖主要盲区。硬凑一个新视角比不加更糟。

写的时候给：新视角身份 → 它会提的那个问题 → 它一出场哪条发现会变（分数从几到几）→ 结论会不会变。

### 5. 模拟一位苛刻的方法论学者

**先声明**：这是按学术评审标准做的模拟审查，不代表任何真实个人。不冒充具体人名，也不编造“XX 教授说过”。

按学术审稿的八个维度逐项查，每项给 pass / weak / fail：

1. **问题定义**：研究对象、人群、时间窗、口径是否清楚（口径不清 = fail）
2. **因果识别**：是否从相关跳到因果，有没有处理内生性/选择偏差
3. **效应量**：是否拿“显著”当“重要”，有没有给区间
4. **外部效度**：结论能从实验环境推到现场吗，边界条件写了吗
5. **证据层级**：轶事、类比、推断被当成证据用了几次
6. **可复现**：第三方能不能按文中的描述重做一遍
7. **文献/反证覆盖**：是否漏了最明显的反面文献和失败案例
8. **利益冲突披露**：出证据的人与结论的利益关系写了吗

然后给：
- **总分**（1–10）与一句话总评
- **必须改的三条（major）**：每条要指出具体是哪句话、哪条证据，以及改成什么
- **可选的两条（minor）**
- **最可能被要求删掉的那一句**：通常是那个指标漂亮但因果不成立的断言

难点在诚实：如果模拟出来只有 5 分，就写 5 分。写给用户开心的分数，会让他在真实评审面前被打得更狠。

## 质量红线

- **不许客套**。任何“整体不错”“建议深入”都是失败输出。
- **不许评分通胀**。五条至少跳三个档位；全高分和全低分都要重做。
- **不许把“最没把握”理解成“最不重要的”**。选影响半径大的，不是选最弱的。
- **不许只指出问题不给修法**。每条扣分都要配一句“升 2 分需要什么”。
- **不许冒充真人点评**。模拟评审必须标明是模拟，不挂真实学者名字。
- **不许无条件加第六个视角**。不满足三条判据就不加，硬加是噪音。
- **评审完必须回答“结论还立不立得住”**。只列毛病不给处置结论，等于把问题退回给作者。

## 与其他技能的分工

- 上游：`five-expert-panel` → `five-expert-conflict-map` → `five-expert-brief`
- 本技能：对简报做对抗性审查，产出分数、脆弱点、缺失视角与改法
- 下游：回修 `five-expert-brief`（根据 major 三条改），或直接进入发布/决策
